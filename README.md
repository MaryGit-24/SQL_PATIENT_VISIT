**Patient Visits Capstone Project (SQL)**

**Overview**
This project simulates a healthcare dataset to manage patient visits, appointments, billing, and doctor performance. The goal is to structure healthcare data using SQL and generate actionable insights via queries and dashboards.

**Tables Created**
- **patients**: Contains patient information such as ID, name, and location  
- **medications**: Records of medications prescribed  
- **doctors**: Doctor details and IDs  
- **diagnoses**: Patient diagnoses linked to appointments  
- **billing**: Billing amounts, insurance coverage, and payments  
- **appointments**: Patient appointments, completion status, and dates  

**Key Features**
- Implemented **complex SQL queries** using Common Table Expressions (CTEs) and views.  
- Queries include analysis of completed appointments, doctor rankings, patient billing, medication dosages, and insurance coverage.  
- Data visualizations created in **Power BI** to provide dashboards for patient trends, billing summaries, and doctor performance.
